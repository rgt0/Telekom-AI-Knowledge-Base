German Coaching

German Coaching (DE + HU)

HU: Rövid, gyakorlatorientált német fejlesztés – magyarázat magyarul, példák németül.

DE: Kurze, praxisorientierte Einheiten – Erklärungen auf Ungarisch, Beispiele auf Deutsch.

Áttekintés / Überblick

HU: Cél: biztos alapok + munkahelyi kommunikáció (meeting, e-mail, státusz, kérdezés).

DE: Ziel: solide Grundlagen + Kommunikation im Arbeitsalltag (Meetings, E-Mails, Status, Nachfragen).

Heti struktúra / Wochenstruktur

1:1 coaching (30–45 perc)

HU: Rövid ismétlés → célzott gyakorlás → mini házi feladat.

DE minta: „Heute üben wir Nachfragen und Zusammenfassen.”

Csoportos session (45–60 perc)

HU: Szituációs gyakorlat (meeting / customer call), szerepek, visszajelzés.

DE minta: „Kannst du das bitte kurz zusammenfassen?”

Mini nyelvtan / Mini-Grammatik

W-Fragen (Mit? Warum? Wie?)

HU: Használd, ha pontosítani akarsz.

  • DE: „Was genau meinst du?” — HU: „Pontosan mire gondolsz?”
  • DE: „Warum ist das wichtig?” — HU: „Miért fontos ez?”
  • DE: „Wie machen wir das?” — HU: „Hogyan csináljuk ezt?”

Udvarias kérés / Höfliche Bitte

HU: Meetingekben és e-mailben szuper hasznos.

  • DE: „Könntest du das bitte schicken?” — HU: „El tudnád küldeni?”
  • DE: „Wäre es möglich, dass …?” — HU: „Megoldható lenne, hogy …?”

Munkahelyi minták / Workplace Patterns

Státusz update / Status-Update

HU: Rövid, struktúrált: kész / folyamatban / blokk.

  • DE: „Ich habe X abgeschlossen.” — HU: „Befejeztem az X-et.”
  • DE: „Ich arbeite gerade an Y.” — HU: „Épp az Y-on dolgozom.”
  • DE: „Ich habe ein Problem mit Z.” — HU: „Problémám van a Z-vel.”

Visszakérdezés / Nachfragen

HU: Ha bizonytalan vagy, kérdezz vissza – ez profi.

  • DE: „Meinst du A oder B?” — HU: „Az A-ra vagy a B-re gondolsz?”
  • DE: „Kannst du ein Beispiel geben?” — HU: „Tudsz példát mondani?”

Gyakorlatok / Übungen

Übung 1 – 3 mondatos státusz

HU feladat: Írj 3 mondatot: kész / folyamatban / blokk.

DE sablon:

  • „Ich habe … abgeschlossen.”
  • „Ich arbeite gerade an …”
  • „Ich brauche Hilfe bei …”

Übung 2 – E-mail (rövid)

HU feladat: Kérj be hiányzó információt udvariasan.

DE minta:

„Hallo …,
könntest du mir bitte … schicken? Wir brauchen das bis …
Danke und viele Grüße,
…”

Anyagok / Materialien

HU: Itt lesznek linkek, szószedet, kifejezéslista.

DE: Hier kommen Links, Glossar, Redemittel.

German Coaching

German Coaching – Arbeitsalltag (70% DE / 30% HU)

HU: Fókusz: munkahelyi német. Rövid magyar instrukciók, sok német “készmondat” + gyakorlat.

Überblick (Áttekintés)

DE: Ziel: sicher sprechen in Meetings, klare E-Mails schreiben, Status geben, nachfragen, Probleme melden.

HU: Cél: meeting, státusz, kérdezés, e-mail, problémakezelés rutinszinten.

Wochenstruktur (Heti struktúra)

1:1 Coaching (30–45 Min.)

DE: Warm-up (5 Min.) → Fokus (20 Min.) → Rolle/Übung (10 Min.) → Mini-Hausaufgabe (5 Min.).

HU: Rövid ismétlés → célzott téma → szerepjáték → mini házi.

Gruppensession (45–60 Min.)

DE: Simulation (Meeting/Call) + Feedback + Redemittel-Liste.

HU: Szituáció + visszajelzés + kifejezéslista.

Redemittel fürs Meeting (Meeting kifejezések)

Start & Agenda

  • DE: „Lasst uns anfangen.” — HU: Kezdjünk.
  • DE: „Die Agenda für heute ist …” — HU: A mai napirend …
  • DE: „Wir haben 30 Minuten.” — HU: 30 percünk van.

Nachfragen (Visszakérdezés)

  • DE: „Kannst du das bitte wiederholen?” — HU: Megismételnéd?
  • DE: „Was genau meinst du mit …?” — HU: Mit értesz pontosan … alatt?
  • DE: „Meinst du A oder B?” — HU: A-ra vagy B-re gondolsz?
  • DE: „Kannst du ein Beispiel geben?” — HU: Tudsz példát mondani?

Zusammenfassen (Összefoglalás)

  • DE: „Wenn ich richtig verstanden habe, …” — HU: Ha jól értem…
  • DE: „Kurz zusammengefasst: …” — HU: Röviden: …
  • DE: „Die nächsten Schritte sind …” — HU: A következő lépések…

Status Update (Státusz)

HU: Tartsd a 3-as struktúrát: kész → folyamatban → blokk/kérés.

3-Satz-Format

  • DE: „Ich habe … abgeschlossen.”
  • DE: „Ich arbeite gerade an …”
  • DE: „Ich brauche Hilfe bei … / Ich habe ein Problem mit …”

Präzise Zeitangaben

  • DE: „Bis Ende des Tages.” — HU: Nap végéig.
  • DE: „Bis morgen 10 Uhr.” — HU: Holnap 10-ig.
  • DE: „Spätestens am Freitag.” — HU: Legkésőbb pénteken.

Incident / Problem (Hiba, akadály)

Problem melden

  • DE: „Ich sehe einen Fehler in …” — HU: Hibát látok …
  • DE: „Das System ist derzeit nicht verfügbar.” — HU: A rendszer jelenleg nem elérhető.
  • DE: „Ich kann das reproduzieren / nicht reproduzieren.” — HU: Reprodukálható / nem.

Impact + Next step

  • DE: „Auswirkung: …” — HU: Hatás: …
  • DE: „Nächster Schritt: …” — HU: Következő lépés: …
  • DE: „Ich brauche dafür …” — HU: Ehhez szükségem van …

E-Mail Templates (E-mail sablonok)

Kurze Bitte (Rövid kérés)

DE:
Hallo …,
könntest du mir bitte … bis … schicken?
Vielen Dank und viele Grüße
…

HU: Udvarias kérés + határidő.

Rückfrage / Clarification

DE:
Hallo …,
ich hätte noch eine kurze Frage: Meinst du … oder …?
Danke!
…

HU: Rövid visszakérdezés e-mailben.

Übungen (Gyakorlatok)

Übung 1 – Status in 3 Sätzen

DE: Schreibe 3 Sätze (abgeschlossen / in Arbeit / Problem oder Hilfe).

HU: Írj 3 mondatot (kész / folyamatban / blokk vagy kérés).

Übung 2 – Mini-Meeting

DE: Verwende 3 Redemittel: 1 Frage + 1 Zusammenfassung + 1 nächster Schritt.

HU: 1 kérdés + 1 összefoglalás + 1 következő lépés.

Übung 3 – Incident Message

DE: Formuliere: Problem → Auswirkung → nächster Schritt.

HU: Hiba → hatás → következő lépés.

Materialien (Anyagok)

DE: Glossar, Redemittel-Liste, Beispieltexte – folgt.

HU: Szószedet és példák – később.
