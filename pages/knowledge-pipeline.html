⚙️ Knowledge Pipeline

A Telekom AI Knowledge Base célja nem csupán dokumentumok tárolása, hanem azok átalakítása strukturált, AI-kompatibilis tudássá.

Ez az oldal bemutatja, hogyan válik egy dokumentumból kereshető, újrahasznosítható és agentek által is felhasználható tudáselem.

📄 1. Dokumentum

A folyamat kiindulópontja egy vagy több forrásdokumentum.

  • DOCX
  • PDF
  • PPTX
  • HTML
  • Markdown
  • TXT

Példák:

  • Használati útmutatók
  • Whitepaperek
  • Pilot dokumentációk
  • Oktatási anyagok

🧠 2. Knowledge Curator Agent

A Knowledge Curator Agent elemzi a dokumentumokat és automatikusan előállítja a tudásbázis artefaktumait.

Feladata:

  • tartalom kivonatolása
  • entitások felismerése
  • kapcsolatok létrehozása
  • RAG csomag generálása
  • repo tartalom előállítása

🔍 3. Entitáskinyerés (EIE)

Az agent azonosítja a dokumentumban található fontos fogalmakat és objektumokat.

Példák: 

Browser AI

Copilot Studio

AIFS

Knowledge Graph

Marketplace

Automation

📦 6. RAG artefaktumok

A dokumentumok AI keresésre optimalizált struktúrában is feldolgozásra kerülnek. 

Document
      ↓
Chunks
      ↓
Metadata
      ↓
RAG JSON

Ezzel válik lehetővé a későbbi AI-alapú keresés.

🕸 7. Tudásgráf

Az entitások és kapcsolatok együtt alkotják a tudásgráf alapját. 

Entities
      +
Relations
      ↓
Knowledge Graph

A tudásgráf segít az összefüggések feltárásában és a tudás újrafelhasználásában.

🤖 8. Agent ökoszisztéma

A jövőben több agent is ugyanarra a tudásbázisra épülhet.

  • Knowledge Agent
  • Learning Coach Agent
  • Tool Advisor Agent
  • Modernization Agent
  • Governance Agent
