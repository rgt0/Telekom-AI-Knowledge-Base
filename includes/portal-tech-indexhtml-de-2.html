Layout CSS (DE): Grid + Sidebar-Scroll + Sticky Topbar

Warum Grid + Flex?

  • DE: .layout nutzt CSS Grid für zwei Spalten: Sidebar + Main.
  • DE: .main nutzt Flex für Topbar (sticky) + Content darunter.
  • DE: Sidebar nutzt Flex: fixe Teile + nur TOC ist scrollbar.

CSS (Beispiel)

.layout{
  min-height: 100vh;
  display: grid;
  grid-template-columns: var(--sidebar-w, 280px) 1fr;
}

.main{
  min-width: 0; /* wichtig gegen horizontales Overflow */
  display: flex;
  flex-direction: column;
}

.topbar{
  position: sticky;
  top: 0;
  z-index: 20;
  height: var(--topbar-h, 56px);
  display: flex;
  align-items: center;
  padding: 10px 14px;
  background: #fff;
  border-bottom: 2px solid var(--border);
}

.sidebar{
  position: sticky;
  top: 0;
  height: 100vh;
  overflow: hidden; /* Sidebar als Ganzes scrollt nicht */
  display: flex;
  flex-direction: column;
  gap: 12px;
}

.sidebar__tocwrap{
  flex: 1 1 auto;
  min-height: 0; /* KRITISCH: damit inneres Scrollen funktioniert */
  display: flex;
  flex-direction: column;
}

#toc.toc{
  flex: 1 1 auto;
  min-height: 0; /* KRITISCH */
  overflow-y: auto;
}

Typische Fehler

  • DE: Kein Scroll in Sidebar → min-height:0 fehlt im Flex-Container.
  • DE: Layout wird „breit“ → min-width:0 fehlt auf .main.
  • DE: Sticky Topbar überdeckt Inhalt → Padding/Offset anpassen oder scrollIntoView mit block:"start".
